1. INICIO RÁPIDO
================================================================================

🚀 Para iniciar el servidor:

1. Abrir terminal en esta carpeta
2. Ejecutar:

   venv\Scripts\python manage.py runserver

3. Abrir navegador en: http://127.0.0.1:8000/

📊 Para poblar datos iniciales:

   python scripts/poblacion/ejecutar_poblacion.py

✅ Para verificar datos:

   python scripts/verificacion/verificar_datos.py

3. COMANDOS ÚTILES
================================================================================

🔧 Django:

   # Iniciar servidor
   venv\Scripts\python manage.py runserver

   # Crear migraciones
   python manage.py makemigrations

   # Aplicar migraciones
   python manage.py migrate

   # Crear superusuario
   python manage.py createsuperuser

   # Abrir shell de Django
   python manage.py shell

   # Recopilar archivos estáticos
   python manage.py collectstatic

📦 Scripts del Proyecto:

   # Poblar datos de documentos (RECOMENDADO)
   python scripts/poblacion/ejecutar_poblacion.py

   # Verificar datos de documentos
   python scripts/verificacion/verificar_datos.py

   # Verificar usuarios
   python scripts/verificacion/verificar_usuarios.py

   # Test de endpoints
   python scripts/tests/test_endpoint.py

🔍 SQLite (Base de Datos):

   # Abrir base de datos
   sqlite3 db.sqlite3

   # Ver tablas
   .tables

   # Salir
   .quit

7. SOLUCIÓN DE PROBLEMAS
================================================================================

❌ Error: "No module named 'django'"

   ✅ Solución: Activar entorno virtual
      venv\Scripts\activate

❌ Error: "db.sqlite3 not found"

   ✅ Solución: Ejecutar desde la carpeta correcta
      cd C:\INFORMACION\Desktop\prototipo_0.1\myworld\app_prototipo

❌ Error: "No such table"

   ✅ Solución: Aplicar migraciones
      python manage.py migrate

❌ Error al subir documentos

   ✅ Solución: Verificar que existe carpeta media/
      mkdir media

❌ No hay tipos de documento

   ✅ Solución: Ejecutar script de población
      python scripts/poblacion/ejecutar_poblacion.py

❌ Puerto 8000 en uso

   ✅ Solución: Usar otro puerto
      python manage.py runserver 8001

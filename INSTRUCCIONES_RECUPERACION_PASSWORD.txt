PASO 1: APLICAR MIGRACIONES
----------------------------
El sistema necesita crear nuevas tablas en la base de datos.

Opción A (RECOMENDADO):
- Ejecuta el archivo: aplicar_migraciones.bat

Opción B (Manual):
1. Abre CMD o PowerShell
2. Navega a: C:\INFORMACION\Desktop\prototipo_0.1\myworld\app_prototipo
3. Ejecuta:
   venv\Scripts\activate
   python manage.py makemigrations usuarios
   python manage.py migrate


PASO 2: VERIFICAR CONFIGURACIÓN
--------------------------------
✓ El sistema está configurado en modo DESARROLLO
✓ Los correos se mostrarán en la CONSOLA (no se enviarán realmente)

Para ver los correos:
- Cuando ejecutes "python manage.py runserver"
- Mira la consola donde aparecer el enlace de recuperación


PASO 3: USAR EL SISTEMA
------------------------
1. Inicia el servidor:
   python manage.py runserver

2. Ve a: http://localhost:8000/usuarios/login/

3. Haz clic en "¿Olvidaste tu contraseña?"

4. Ingresa un correo electrónico registrado

5. Mira la CONSOLA del servidor - ahí aparecerá el enlace

6. Copia el enlace y ábrelo en tu navegador

7. Establece tu nueva contraseña


CONFIGURACIÓN PARA PRODUCCIÓN (OPCIONAL)
-----------------------------------------
Si quieres enviar correos REALES:

1. Abre: app_prototipo/settings.py

2. Ve a la línea 206 y comenta:
   # EMAIL_BACKEND = 'django.core.mail.backends.console.EmailBackend'

3. Descomenta las líneas 211-217 y configura tu SMTP

Para Gmail:
- EMAIL_HOST = 'smtp.gmail.com'
- EMAIL_PORT = 587
- EMAIL_USE_TLS = True
- EMAIL_HOST_USER = 'tu_correo@gmail.com'
- EMAIL_HOST_PASSWORD = 'tu_contraseña_de_aplicación'

IMPORTANTE: Para Gmail necesitas crear una "Contraseña de aplicación":
https://myaccount.google.com/apppasswords

SOLUCIÓN DE PROBLEMAS
----------------------
❌ Error: "No module named 'django'"
   → Activa el entorno virtual: venv\Scripts\activate

❌ Error al crear migraciones
   → Asegúrate de estar en el directorio correcto
   → Verifica que el entorno virtual esté activado

❌ No recibo correos
   → En desarrollo, los correos se muestran en la CONSOLA
   → No en tu bandeja de entrada real

❌ El enlace no funciona
   → Verifica que el token no haya expirado (1 hora)
   → Verifica que no hayas usado el token antes
